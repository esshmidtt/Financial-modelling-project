## 🌟 Сильные стороны работы

* **Кросс-чекинг 3 методов (FCFF, APV, FTE):** Денежные потоки рассчитаны параллельно тремя подходами. Применение APV позволило изолировать эффект налогового щита ($PVTS = \$556\text{ млн}$) от привлечения $8.3 млрд долга.
* **Консервативный прогноз цены золота:** Использован 50-летний тренд (CAGR 8.64%, 1975–2025 гг.). Цены на 2026–2027 гг. ($3,727 и $4,049/унц.) заложены существенно ниже консенсуса инвестбанков (J.P. Morgan), что обеспечивает встроенный margin of safety.
* **Ставка дисконтирования по Дамодарану:** Учтена специфика развивающегося рынка через расчет странового риска (CRP 3.90%, ERP 4.41%, $R_f = 13.0\%$) и де-леверидж отраслевой беты глобальных аналогов ($\beta_u \approx 0.68$). Итоговый WACC ~17.2–17.4% адекватно отражает геополитическую премию.
* **Детальный учет налогового режима (РИП):** В модели воспроизведены фазированный льготный налог на прибыль (0% → 10% → 25%) и повышающие коэффициенты по НДПИ.
* **Стресс-допущения по операционной части:** Объем добычи занижен относительно гайденса компании (2.0 млн унций против 2.3 млн), SG&A зафиксированы по верхней исторической планке (6% выручки).
